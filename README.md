# AdminDark for Typecho

给 Typecho 后台（`/admin/`）加一套深色皮肤。不改后台模板文件，纯靠插件钩子注入样式与脚本。

- **五种配色**：石墨 / 午夜蓝 / 深紫 / 松林 / 暖褐
- **三种模式**：跟随系统 / 亮色 / 深色
- **每用户独立**：选择存在 cookie 里，不影响别人
- **零数据改动**：停用插件只解除钩子，不碰数据库与用户配置

---

## 安装

1. 下载源码，**文件夹必须命名为 `AdminDark`**
2. 上传到 `usr/plugins/`，最终结构为 `usr/plugins/AdminDark/Plugin.php`
3. 后台 → 控制台 → 插件 → 启用「AdminDark」

启用后，后台页面右上角（或右下角，取决于设置）会出现「自动 / 亮色 / 暗色」切换按钮，
旁边是「配色」按钮，可以随手换一套试试。

---

## 设置项

后台 → 插件 → AdminDark → 设置：

| 配置 | 说明 |
|---|---|
| 默认模式 | 第一次访问（还没有 cookie）时用哪种。选「跟随系统」由浏览器/操作系统的深色偏好决定 |
| 切换按钮 | 隐藏后仍会按默认模式生效，只是页面上不出现按钮 |
| 配色方案 | 深色档用哪套配色。导航栏里的「配色」按钮可以随时临时切换（只影响你自己） |
| 按钮位置 | 「顶部导航右侧」与后台原有菜单同一行；「右下角悬浮」固定在视口右下角 |
| 深色模式强调色 | 链接、主按钮、选中态的强调色，留空用内置默认值 |
| 自定义深色 CSS | 追加在内置深色样式之后，用来微调个别地方（不要写 `<style>` 标签） |

## 配色方案

| 键 | 名称 | 背景 | 面板 | 强调色 |
|---|---|---|---|---|
| `graphite` | 石墨（默认） | `#1b1e23` | `#242830` | `#5d9cbf` |
| `midnight` | 午夜蓝 | `#12161d` | `#1a212b` | `#4f9bd8` |
| `plum` | 深紫 | `#1a1520` | `#241d2c` | `#a37bd8` |
| `forest` | 松林 | `#131b17` | `#1c2620` | `#5fb98c` |
| `ember` | 暖褐 | `#201a15` | `#2a231c` | `#d4915c` |

加一套新配色 = 在 `Plugin.php` 的 `SCHEMES` 里加一行 + 在 `assets/dark.css` 里
加一段 `html[data-admin-scheme="键名"]` 覆盖。

## 自定义样式

插件把几乎所有颜色都抽成了 CSS 变量（`--ad-bg`、`--ad-surface`、`--ad-line`、
`--ad-fg`、`--ad-fg-dim`、`--ad-accent`、`--ad-ok` / `--ad-warn` / `--ad-danger` 等），
所以：

- **只想换强调色**：设置里填「深色模式强调色」即可
- **想改更多**：写进「自定义深色 CSS」，例如

```css
.typecho-page-title { letter-spacing: .5px; }
#ad-toggle { border-radius: 999px; }
```

- **想让别的插件也跟随深浅色**：直接引用这些变量，插件没启用时会落到兜底色，不会坏

```css
.my-box { border: 1px solid var(--ad-line, #ddd); background: var(--ad-surface, #fff); }
```

## 说明

- 挂载的钩子只有两个：`admin/header.php` 的 `header`（样式 + 首屏定色脚本，
  避免深色用户看到白屏一闪）与 `admin/footer.php` 的 `end`（切换按钮 + 交互脚本）。
- 用户的选择存在 cookie `admin_dark`（`auto` / `light` / `dark`）与
  `admin_dark_scheme`（配色键名）里。
- **停用插件不删任何数据**，重新启用后每个人原来的选择照旧。
- 只处理固定的色值体系，不注入裸 `<style>` 之外的第三方资源。
